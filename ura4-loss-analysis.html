URA4 LOSS FREQUENCY CALCULATOR

Calculate ura4 loss frequency from paired YES and YES + 5-FOA colony counts, normalized to plating survival. Each independently plated culture is entered as one paired observation. The calculator also summarizes optional eviction/conversion characterization and allows user-defined statistical comparisons between strains.

COLONY COUNT INPUT

Paste one count per line into each box. The YES and 5-FOA lists must contain the same number of values. 0 is a valid measurement.

FINAL RESULTS

STATISTICAL COMPARISONS

Define only the biological comparisons you want to test. The statistics apply to ura4-loss frequency only. Eviction/conversion data are not used for statistical testing.

EVICTION / CONVERSION CHARACTERIZATION

Optional. Enter the number of characterized colonies for each strain. Leave blank when these data are not available. Blank means missing data; it is not treated as zero.
