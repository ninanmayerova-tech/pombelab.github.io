URA4 LOSS FREQUENCY CALCULATOR

This calculator determines ura4 loss frequency from paired YES and YES + 5-FOA colony counts. The 5-FOA count is normalized to the survival measured on the corresponding YES plate, so differences in plating/survival efficiency are taken into account.

Calculation: survival = YES colonies / 100. Survival-corrected 5-FOA colonies = 5-FOA colonies / survival. Ura4 loss frequency (%) = survival-corrected 5-FOA colonies / 100,000 × 100. Zero is a valid measurement and is retained in the analysis.

COLONY COUNTS

Enter one paired YES and 5-FOA count for each independently plated culture. You can paste an unlimited number of values into either fast-input box. The YES and 5-FOA lists must contain the same number of values.

STATISTICAL COMPARISONS

Define only the biological comparisons you want to test. The calculator uses the individual colony frequencies for a Welch two-sample t-test. Welch’s test does not assume equal variances between groups; the statistical units should be independent biological replicates. Eviction/conversion data are not used in these statistical tests.

EVICTION / CONVERSION CHARACTERIZATION

Optional descriptive data. Enter the number of characterized 5-FOA colonies classified as eviction or conversion for each strain. Blank fields mean that data are not available; zero means that zero colonies were observed.
